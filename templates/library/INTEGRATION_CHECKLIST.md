# Integration Checklist - library Template

Two ways to use this template: as a standalone package or integrated into the test-cto monorepo.

## Option A: Standalone Package

### 1. Initialize

```bash
cp -r templates/library my-lib
cd my-lib
```

### 2. Install Dependencies

```bash
pnpm install
```

### 3. Configure Package

Edit `package.json`:

```json
{
  "name": "@your-scope/my-library",
  "version": "1.0.0",
  "description": "Your library description"
}
```

### 4. Build and Publish

```bash
pnpm build
pnpm publish
```

---

## Option B: Monorepo Integration

### 1. Copy to Packages

```bash
cp -r templates/library packages/my-lib
```

### 2. Update pnpm-workspace.yaml

Add the new package to workspaces.

### 3. Configure package.json

```json
{
  "name": "@myapp/my-lib",
  "exports": {
    ".": {
      "types": "./dist/index.d.ts",
      "import": "./dist/index.js",
      "require": "./dist/index.cjs"
    },
    "./utils": {
      "types": "./dist/utils.d.ts",
      "import": "./dist/utils.js",
      "require": "./dist/utils.cjs"
    }
  }
}
```

### 4. Build and Use

```bash
pnpm install
pnpm build

# Use in other packages
import { myFunction } from '@myapp/my-lib'
```

## Common Integration Tasks

### Adding New Exports

```typescript
// src/new-feature.ts
export function newFeature() {
  return 'new feature'
}
```

```typescript
// src/index.ts
export * from './new-feature'
```

### Type Declarations

```typescript
// src/index.ts
export function myFunction(): string

// Automatic types are generated by tsup
```

### Adding Tests

```typescript
// tests/new-feature.test.ts
import { describe, it, expect } from 'vitest'
import { newFeature } from '../src/new-feature'

describe('newFeature', () => {
  it('returns new feature', () => {
    expect(newFeature()).toBe('new feature')
  })
})
```
